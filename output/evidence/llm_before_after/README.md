# LLM 조치안 환각 — Before / After 비교 기록

목적: `prioritize.py`/`remediate.py`가 NVD에서 조회한 "공식 수정 버전"을 프롬프트 근거에
포함하고, 시나리오 설명에서 "ajp" 같은 특정 메커니즘 암시 단어를 제거하면 LLM 환각
(패치 버전 혼동, 무관한 대안 제시)이 줄어드는지 실제 호출로 검증한 기록이다. 모델은
`gpt-4o-mini-2024-07-18`, 3단계(before → v1 → v2)를 전부 실제 OpenAI 호출로 재현했다.

## 결론

| 환각 유형 | Before | v1 (NVD 수정 버전만 추가) | v2 (+ 중립적 시나리오 설명, reachable=None 가드) |
|---|---|---|---|
| 패치 버전 혼동 | CVE-2025-24813에 Ghostcat의 9.0.31을 잘못 제시 | **해결** — 9.0.99로 정확히 수정 | 유지(해결 상태) |
| 무관한 AJP/대안 언급 | CVE-2025-24813·CVE-2023-44487에 AJP 비활성화를 끼워넣음 | **미해결** — 여전히 AJP 언급 발생 | **해결** — 두 CVE 모두 무관한 메커니즘 언급 사라짐 |

v1만으로는 패치 버전 문제는 풀렸지만 "무관한 메커니즘 언급"은 그대로였다. 원인을 추적해보니
프롬프트에 그대로 박아 넣은 시나리오 식별자 문자열 `"ajp-vulnerable"` 자체가 모델에게
"AJP와 관련된 응답을 하라"는 암묵적 신호로 작용한 것으로 보인다(reachability 근거에는
AJP가 전혀 언급되지 않는 CVE인데도 발생). v2에서 이 문자열을 중립적 설명("레거시/방치된
설정 묶음 (시나리오 A)")으로 바꾸고, `reachable=None`인 CVE에는 "특정 컴포넌트명을 추측하지
말라"는 가드 문구를 명시적으로 추가하자 두 환각이 모두 사라졌다.

## 구체적 비교 — CVE-2025-24813

- **Before**: "취약점을 해결하기 위해 **Tomcat을 9.0.31 이상**의 패치 버전으로
  업그레이드해야 합니다. 또한, **AJP 프로토콜을 비활성화**하거나, 방화벽을 통해 AJP 포트를
  차단하여..." — ❌ 수정 버전 오류(정답 9.0.99), ❌ AJP는 이 CVE와 무관
- **v1**: "...Tomcat을 **9.0.99**로 업그레이드해야 합니다." (버전 정정됨) / "...AJP 커넥터의
  접근을 제한하여 외부 접근을 차단합니다." — ✅ 버전 정정, ❌ AJP 언급 여전히 잔존
- **v2**: "패치 버전 업그레이드는 9.0.30에서 **9.0.99**로 진행해야 합니다. 추가적으로,
  **DefaultServlet의 readonly 속성을 true**로 설정하여..." — ✅ 버전 정확, ✅ 실제 관련
  메커니즘(DefaultServlet)만 언급, AJP 언급 소멸

## 구체적 비교 — CVE-2023-44487 (HTTP/2 Rapid Reset, AJP와 전혀 무관한 CVE)

- **Before**: "...버전을 libnghttp2-14@1.36.0-3, **tomcat-api@9.0.31, tomcat-coyote@9.0.31**
  등으로 업그레이드..." (정답 9.0.80과 다름, Ghostcat 버전과 혼동) / "**AJP 프로토콜을
  비활성화**하거나 대체 통제를 통해..." — ❌ 버전 오류, ❌ AJP 무관 언급
- **v1**: "해당 서비스를 패치하여 버전을 **9.0.80**으로 업그레이드..." (버전 정정됨) /
  "...**AJP 커넥터를 비활성화**하거나 **DefaultServlet의 readonly**를 설정..." — ✅ 버전
  정정, ❌ 무관한 메커니즘 2개나 추가로 등장(오히려 악화)
- **v2**: "영향받는 버전인 9.0.30에서 공식 수정 버전인 **9.0.80**으로 패치...또한, **해당
  기능이나 포트를 비활성화**하여 추가적인 보안을 강화할 수 있습니다." — ✅ 버전 정확,
  ✅ 구체적 컴포넌트명을 지어내지 않고 일반적 표현으로 대체

## 비용 메모

근거 라인·가드 문구 추가로 호출당 prompt 토큰이 늘어 총 토큰은 Before 4,351 → v1 5,609 →
v2 5,542로 약 25~29% 증가했다. 환각 감소와 맞바꾼 트레이드오프이며, 상위 N건(기본 3건)에만
LLM을 쓰는 비용 통제 설계 덕분에 절대 비용 자체는 여전히 작다(gpt-4o-mini 기준 6회 호출에
1센트 미만).
